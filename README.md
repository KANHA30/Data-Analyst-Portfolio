# Data Analyst Portfolio Website

A responsive portfolio website designed to showcase data analytics projects, dashboards, technical skills, and data visualization work.

## 🌐 Live Demo

**Portfolio:** https://mydatanalysis.netlify.app/

## 🚀 Featured Projects

### Sales Performance Dashboard — Excel
- Analyzed sales and profit performance.
- Created KPI summaries and PivotTables.
- Visualized sales by category, region, and month.
- Identified trends using charts and data analysis.

### Sales Performance Dashboard — Power BI
- Built an interactive sales dashboard.
- Created KPI cards and DAX measures.
- Compared sales and profit across categories and regions.
- Added interactive slicers for data exploration.

*Both projects use sample sales data for demonstration purposes.*

## ⚙️ Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or installation is required.
